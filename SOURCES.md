# Polices locales

Téléchargées depuis Google Fonts le 17 octobre 2026. Les fichiers sont servis localement : aucune requête vers Google Fonts n'est nécessaire à l'exécution du site.

- `barlow-condensed-latin-600.woff2` : Barlow Condensed, graisse 600, style normal, sous-ensemble latin (22 308 octets).
- `manrope-latin-variable.woff2` : Manrope, police variable, plage CSS demandée 400–700, style normal, sous-ensemble latin (24 836 octets).

Les sous-ensembles latins comprennent les accents français courants, ç, œ/Œ, les apostrophes typographiques, les tirets et le symbole euro. Pour d'autres alphabets ou caractères étendus, récupérer les sous-ensembles nécessaires.
